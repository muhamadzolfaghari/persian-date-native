# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability within `persian-date-native`, please follow these steps:

1. **Do not create a public issue.**
2. Report the vulnerability privately via [GitHub Security Advisory](https://github.com/muhamadzolfaghari/persian-date-native/security/advisories/new) or by opening a confidential discussion with the maintainers.
3. Provide detailed steps to reproduce the vulnerability, including:
   - Node.js runtime / Browser version
   - Operating system
   - Code snippet demonstrating the issue

We appreciate your responsible disclosure and will acknowledge, evaluate, and patch valid security vulnerabilities promptly.
