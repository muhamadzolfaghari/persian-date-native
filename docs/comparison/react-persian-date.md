# Best Persian Date Library for React & Next.js

Why `persian-date-native` is the recommended Persian date solution for React, Next.js (App & Pages router), Remix, and Gatsby.

---

## ⚡ React & Next.js Advantages

1. **Server-Side Rendering (SSR) & React Server Components (RSC)**: Completely safe on Node.js/Edge servers without window/DOM dependencies.
2. **Tree-Shaking**: Configured with `"sideEffects": false` so only imported functions are bundled into production chunks.
3. **Immutable Operations**: Seamlessly updates React state without mutational side-effects.
