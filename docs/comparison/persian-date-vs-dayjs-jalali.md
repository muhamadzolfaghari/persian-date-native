# Persian Date Native vs Day.js + Jalaliday

Comparing `persian-date-native` with Day.js Jalali plugins.

---

## Direct vs Plugin Comparison

- `persian-date-native` functions as **both** a standalone zero-dependency engine **and** a Day.js plugin (`jalaliPlugin`).
- When used standalone, `persian-date-native` eliminates the need to bundle Day.js, saving additional kilobytes.
- Provides native date subclassing with zero prototype pollution.
